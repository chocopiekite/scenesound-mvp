파일 처리·보관 안내

파일은 이 컴퓨터의 임시 작업 폴더에서 처리해요. 음성 구분 모델도 로컬에서 실행하며 사용자 오디오를 외부 분석 API로 보내지 않아요.

대사 트랙 확인

말소리가 섞인 트랙을 선택해 주세요. 선택하지 않은 트랙도 원본 AAF에 그대로 남아요. OMF·GUIDE와 DIA B·WALLA는 기본적으로 게인을 수정하지 않아요.

위치·길이·원본 오디오·게인이 같은 클립만 제외해요. 겹쳐 말하는 대사와 다른 마이크 녹음은 유지해요.

같은 원본 샘플이 겹치면 equal-gain을 사용해 소리가 부풀지 않게 해요. 불확실한 경계는 보류해요.

작은 대사·배경 노이즈는 무음으로 삭제하지 않아요. 원본 오디오 샘플은 바꾸지 않아요.

씬과 기준 클립 · 선택

같은 장소·상황 안에서 기준 룸톤을 공유해요. 씬마다 기준 클립을 직접 고르거나 자동 선택할 수 있어요. 3초 숏텀·피크·룸톤 조건에 맞는 기준이 없으면 원래 게인을 유지해요. 트랙 배치는 원본 그대로예요.

여러 씬이 있는 AAF는 경계를 나눠 주세요. 자동 선택한 기준과 보류 내역은 처리 후 확인할 수 있어요.

미리듣기·내보내기는 마지막 처리 결과예요. 변경한 설정은 다시 처리하면 적용돼요.
